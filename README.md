# VEIN

Halloween MVP — discreet visual vein analysis PWA for iPhone Safari.

Fictional profiles from real image features. Not a medical device.

## Develop

```bash
npm install
npm run dev
npm run build
npm run fixture:check
```

## iPhone

1. Open the HTTPS deploy URL in Safari
2. Tap **Begin analysis** and allow camera
3. Share → **Add to Home Screen**
